# Banned Words

Replace on sight. Zero tolerance in body copy.

| Banned | Replacement |
|--------|-------------|
| unlock | name what becomes possible |
| leverage / harness | use, apply, build on |
| effortlessly / seamlessly | cut or describe what was hard |
| empower | let, give [X] the ability to |
| surface (verb) | find, show, flag |
| supercharge | describe the specific improvement |
| game-changer / breakthrough | describe what changed |
| paradigm shift | describe the structural change |
| next-generation / cutting-edge | name the specific advance |
| best-in-class | name the comparison and the metric |
| synergy | describe the specific interaction |
| holistic | name what's included |
| robust | describe the specific property |
| end-to-end (unless literal process) | name the boundaries |
| ecosystem (unless literal platform) | name the components |
| north star | state the goal |
| lean into | pursue, accept, emphasise |
| landscape / space | market, field, or name it |
| stakeholder | name who: customers, investors, the team |
| bandwidth (for human capacity) | time, attention |
| innovative | name what changed |
| iconic | cut |
| facilitate | help, enable |
| meaningful | name the consequence |
| proactive | name the action |

**Also flag:** "This is not a theoretical concern," "The critical finding:," "with [adjective] precision," sentences starting with "It's worth noting that" or "Importantly," "In an era of," "At the end of the day," "The real question is not X but Y."

**Aphoristic couplets:** "X carries over. Y does not.", "A filters. B never signs.", "No X, no Y.", "…and so was the blame.", "Those three words matter most.", a closing line built to be quoted. Rewrite as one plain sentence.

**Coined labels:** any term the piece invents and defines in brackets ("action class", "autonomy ratchet", "fan-out problem"). Describe the thing instead.

**Counts in headers:** "Eight routines…", "Four ways…".
