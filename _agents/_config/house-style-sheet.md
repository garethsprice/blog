# House Style Sheet

Running record of mechanical decisions for the blog, so every post is edited the same way. Seeded on 2026-09-23 from a survey of the 25 posts in `../_posts/`. Stage 07 checks every draft against this sheet and proposes additions; the author approves them. The parent style guide overrides this sheet where they conflict.

Entries marked **OPEN** are inconsistent in the archive and need an author decision. Until decided, stage 07 applies the stated default silently, without a query.

## Spelling

| Decision | Note |
|---|---|
| British spelling: *behaviour*, *defence*, *organisation*, *authorised*, *centralised* | **OPEN**: archive has 48 *-ise* forms to 28 *-ize*, *behaviour* 9 to *behavior* 6. Default British *-ise*. |
| Spell names as the source spells them, including in quotations (*Auftragstaktik*, *Chinggis Khan*) | |

## Punctuation

| Decision | Note |
|---|---|
| Double straight quotation marks `"…"`; single inside double | Archive: 766 straight, 0 curly. Kramdown renders them. |
| Full stop and comma inside the closing quotation mark | **OPEN**: archive has 103 inside to 1 outside (American style), which clashes with British spelling. Default inside. |
| Serial (Oxford) comma | Archive uses it consistently. |
| Em dash spaced: ` — ` | Archive: 644 spaced, 25 unspaced. Fix unspaced. |
| En dash for ranges, unspaced: *10–20%*, *1976–1984* | |

## Numbers and dates

| Decision | Note |
|---|---|
| Dates day-month-year: *9 October 1805* | Archive: 8 to 3 month-day. Fix month-day forms. |
| *%* with figures, not *per cent* | Archive: 72 to 12. |
| One to ten in words, 11+ in figures (style guide) | |
| Centuries in words: *the mid-second century BC* | |

## Capitalisation

| Decision | Note |
|---|---|
| Post titles in title case: *Agents Need Standing Orders and Fewer Approvals* | Archive: 24 of 25 titles. Capitalise short verbs (*Is*); lowercase articles, conjunctions and prepositions of three letters or fewer unless first word. Fix *Default is Destiny* → *Default Is Destiny* when next updated. |
| H2/H3 headings in sentence case: *Explain what success means* | |
| Historical and period names lowercase unless proper: *the American civil war* (Economist style) | |
| *the Pentagon*, *the White House*, *the US Army*, *US Air Force* | *US* without points. |
