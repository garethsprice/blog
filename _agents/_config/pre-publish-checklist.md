# Pre-Publish Checklist

Run before stage 07 output. Every item must pass.

- [ ] First two sentences carry a specific claim, tension or reader scenario? Thesis stated by the second paragraph?
- [ ] Zero banned words in body?
- [ ] Every factual claim has a specific referent (number, name, date, example)?
- [ ] Every citation verified against actual source? Unverified flagged with `[SOURCE NEEDED]`?
- [ ] Mechanism separated from interpretation throughout?
- [ ] Every H2/H3 carries a claim or names the question the section answers? No counts, no compound claims?
- [ ] Every historical example and quotation followed by a sentence applying it to the reader's case? One precedent per point?
- [ ] Every quotation earns its exact wording (else paraphrase)?
- [ ] No aphoristic couplets, coined labels or closing zinger?
- [ ] Practical guides: worked example appears in each main section? Reader addressed as "you"? Ends on a next action?
- [ ] Named author attribution (Gareth Price)?
- [ ] Strongest counterargument engaged?
- [ ] Visual placement noted if needed (screenshot, diagram — not stock photo)?
- [ ] Closing adds — no restatement, no wind-down, no zinger?
- [ ] Within word count target from brief?
- [ ] Read aloud test: smart colleague or press release?
- [ ] Latest cold-reader check (stage 05) matched the brief's thesis, with no guessed terms left unresolved?
- [ ] Code blocks, commands, config values and quotations unchanged since research/draft?
- [ ] No `[REVIEW]` markers left in the body?
- [ ] Technical terms introduced for the named audience?
- [ ] Standfirst in the right format for the content type (essay: status shift → gap + consequence; practical guide: reader's decision → source of the advice)? Plain, no antithesis couplet?
- [ ] SEO description present, under 160 chars?
- [ ] Publication date set?
